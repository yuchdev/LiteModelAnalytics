# Model Analytics

A production-quality Python library and CLI for request-aware LLM model analytics, comparison, and selection.

## Overview

Model Analytics provides evidence-based tools for:

- Cataloging LLM models from OpenRouter and LiteLLM
- Estimating request costs with Decimal precision
- Matching models to request requirements
- Selecting models based on policies (cheapest, best, fastest, etc.)
- Pareto-frontier analysis across cost/quality/latency/reliability

See the [architecture](architecture.md) for design details.
